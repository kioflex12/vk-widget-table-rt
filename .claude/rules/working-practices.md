# Практики работы над виджетом

Проект крошечный (3 файла), но эти практики окупаются на разведке (VK/Sheets API), рефакторинге и при выдаче рекомендаций.

## 1. Консилиум перед нетривиальной рекомендацией
Перед тем как выдать диагноз бага, выбрать подход или заявить «причина в X» — прогони гипотезу через `/consilium` (skeptic + engineer + quality-gate, остальные по релевантности). Если консилиум отверг — не выдавай рекомендацию, честно скажи об этом. Не гоняй консилиум на фактологии («что делает parseCsv») и на просьбах «дай код».

## 2. Делегируй объёмное — с точными якорями
Когда спавнишь субагента (`Explore`, `general-purpose`, advisor'ы) по теме, которую ты уже изучил в этой сессии, передавай **точные** якоря: `file:line`, имя функции, готовый паттерн для переиспользования (`escapeHtml`, `buildProfileUrl`, `parseCsv`) — а не «посмотри в app.js». Размытая подсказка заставляет субагента переоткрывать всё с нуля grep'ом, и именно это, а не сама правка, съедает время.

## 3. Держи главный контекст маленьким и плотным
Качество модели деградирует от объёма контекста задолго до лимита — не жди «пока заполнится».
- **В субагента** гони объёмное: разведочные grep-свипы, tool-output > ~200 строк, длинные `git diff`/логи, рутинные циклы «правка→ошибка→правка», изучение внешнего API. Субагент возвращает **дистиллят**, сырьё в главное окно не попадает.
- **Читай сам** один файл в пределах ~200 строк, когда нужен дословный кусок (например точный `old_string` для Edit) — тут round-trip через субагента дороже.
- **Retrieval, не load-everything.** Не заливай доки/код впрок — доставай точечно, just-in-time.

## 4. Релиз-инвариант (жёсткое правило проекта)
При **любом** коммите, меняющем `app.js`/`styles.css`/`index.html`:
1. Инкрементируй **patch**-цифру `VERSION` в [app.js](../../app.js) (`1.0.6` → `1.0.7`), только patch.
2. Обнови cache-busting `?v=...` у `<link>`/`<script>` в [index.html](../../index.html).
Без этого пользователи GitHub Pages не получат новый код. Это первое, что проверяет quality-gate консилиума.

## 5. Секреты — никогда в git
Community-токен VK добывается в рантайме через VK Bridge, не хардкодится. Service-account JSON / OAuth secret / любой токен → только в `.gitignore`, не в код. `PUB_ID`/`app_id` — публичны, это не секрет.
